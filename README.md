# zozo-visual-evidence

Before/after screenshots posted on `RoundhouseOrg/zozo` Pull Requests by its
`visual-evidence` GitHub Actions workflow. Every image is rendered from
synthetic fixtures; nothing here comes from a live system.

Layout: `pr-<number>/<head-sha>/<scenario-id>-{before,after}.png`.

Files are append-only. Pull Request comments link to them by raw URL, so
deleting or rewriting history here breaks the evidence on merged Pull Requests.
